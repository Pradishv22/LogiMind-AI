# 📌 Overview

LogiMind AI is an AI-powered Logistics Decision Intelligence Platform designed to help logistics companies monitor operations, predict risks, and make intelligent business decisions using Machine Learning and Generative AI.

The platform integrates shipment tracking, fleet monitoring, warehouse management, predictive analytics, and AI-generated recommendations into a unified dashboard for logistics managers.

---

# 🚀 Problem Statement

Modern logistics operations rely on multiple disconnected systems, making it difficult to monitor shipments, optimize fleets, predict delays, and identify operational risks in real time.

Common challenges include:

- Shipment delays
- Vehicle breakdown risks
- Warehouse capacity issues
- Route inefficiencies
- High operational costs
- Manual decision-making

Organizations need intelligent systems that transform operational data into actionable business insights.

---

# 💡 Solution

LogiMind AI combines Machine Learning and Google Gemini AI to deliver intelligent logistics recommendations.

The system:

- Collects logistics data
- Predicts operational risks
- Detects bottlenecks
- Generates AI-powered business recommendations
- Supports proactive logistics decision making

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Pradishv22/LogiMind-AI.git
```

## Install Frontend

```bash
npm install
```

## Install Backend

```bash
cd backend
npm install
```

## Start Backend

```bash
npm start
```

## Start Frontend

```bash
npm run dev
```
